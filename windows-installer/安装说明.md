# DSH 画布插件 Windows 初级版

## 安装

1. 先安装并启动一次 DSH Desktop，然后完全退出 DSH。
2. 解压本安装包。不要直接在 ZIP 内运行脚本。
3. 双击 `安装画布插件.cmd`。脚本会调用本目录的 PowerShell 安装器。
4. 如果系统阻止脚本，在此目录打开 PowerShell，运行：

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\windows-installer\install.ps1
   ```

5. 重新打开 DSH，启用设计模式并打开画布。

安装器会同步 `profiles/node_modules/@local` 和 `profiles/desktop/node_modules/@local` 两层，并向 web、desktop 和检测到的活动 Profile 注入画布插件。

## 初级版支持

- 无限画布、拖动、缩放和绘制
- 新建、导入、切换及持久化画布项目
- 外部图片拖入和剪贴板粘贴
- 聊天图片明确点击“加入画布”
- 选中一张或多张画布图片发送至聊天
- PNG 导出
- 在 Windows 资源管理器打开项目或定位图片
- PSD、AI、SVG、PDF 作为链接文件保存；转换器不可用时显示安全占位预览

## 渐进增强功能

- OCR、去背景、PSD 生成和转矢量需要 Python 3.11。
- PSD/AI 编辑第一版通过 Windows 文件关联打开；请先让 `.psd` 关联 Photoshop、`.ai` 关联 Illustrator。
- Photoshop 原生文字层自动执行目前只在 macOS 完整支持。Windows 会生成 PSD 草稿并打开，不影响基础画布。
- `dsh-codex` 是否可用取决于它自身的 Windows 版本；API 图片引擎不依赖该插件。

## 检查和恢复

```powershell
.\windows-installer\health-check.ps1
```

安装器默认创建登录自动恢复任务。DSH 更新后如果画布入口消失，重新运行 `install.ps1` 即可。

测试时请记录：Windows 版本、DSH 版本、安装日志和复现步骤。日志位于：

```text
%USERPROFILE%\.dsh\logs\dsh-canvas-windows.log
```
