## 4. 关键机制（接手前必须理解）

1. **谁打开什么**：只读流程（列图层/缩略图/提取）一律打开 `<tmpdir>/dsh-canvas-ai-read-*/source.ai` **副本**；
   生成/写回流程打开 `<tmpdir>/dsh-canvas-layer-*/...`。用户正式文件只在**最后落盘**时被写。
2. **文档关闭**：`runIllustratorJsx` 收尾按 `openPath` **精确关闭**（AppleScript `whose file is POSIX file …`）；
   只在没有 `openPath` 时才退回"整体清场"。Illustrator 2026 的 ExtendScript **没有 `CloseOptions`**，
   正确枚举是 `SaveOptions.DONOTSAVECHANGES`；JSX 内先尽力自关，宿主再兜底。
3. **层叠自检**：`.ai` 写回不靠语义猜测——先用唯一名字给新元素打锚点，`move` 之后遍历 `doc.pageItems`
   读回索引，只有等于目标索引才算成功，否则换下一种 move 语义。返回值带 `z=实际/期望+方式`。
4. **`dshScratch`**：图层编辑的临时提取图层。它落在 `outputs/`（不在素材扫描范围），
   因此**同时**要跳过"访达删除对账"和"删除归档"两条路径，否则会被莫名移除或误进回收站。
5. **占位图**：`dshEditState: 'processing'` 的元素由 iframe 以 DOM 浮层展示（`dsh-pending`），
   会被写进 `canvas.json`。正常结束由 `image-edit-result` / `image-edit-error` 消费；超时由 25 分钟扫描兜底。
6. **写回语义**（用户选定）：`.ai` → 覆盖原文件 + 原图层保留 + 新层叠加在上 + 改前备份；
   `.psd / .svg` → 另存 `-图层编辑` 新版本。**这个差异是有意的**，响应里的 `mode` 字段是唯一判据。

## 6. 下一步建议（用户已明确在考虑的方向）

用户提出：**把入口搬到宿主侧——在 PS / AI 里做插件，把选中图层送到画布编辑，结果回传宿主**。
评估结论（2026-09 现状已核实）：

- Illustrator 的 **UXP 至今未对第三方开放**（仅 NDA 预发布，无公开 API/时间表）；
  Photoshop 的 UXP 自 2021 年公开。**CEP 是唯一同时支持 PS 和 AI 的公开面板框架**，Adobe 未宣布弃用。
- 最便宜的第一版：两个 `.jsx` + ScriptUI/脚本菜单，**文件投放箱**桥接
  （`~/.dsh/canvas-bridge/{outbox,inbox}` + `job.json`），不要走 DSH 网关——实测 `curl 127.0.0.1:43120` 一律 **403**
  （需要桌面授权，跨进程拿不到）。
- 画布侧 `/edit-layer` 只吃 `{path, layerId, layerName, prompt, maskData}`，这些字段正好能由 `job.json` 提供，
  **编辑/引擎/蒙版/写回逻辑可原样复用**；`outbox/` 甚至可以直接设成现有素材库目录（零新代码）。
- 最大收益：Illustrator 没有"图层导出 PNG"的 API，现在靠画布进程隔空截屏，坑全在这条链上；
  改到宿主侧执行后，AppleScript 权限、文档生命周期、抢前台这些问题一次性消失。
- 建议顺序：先做完本文 §5 的真机验收形成可用基线 → 再做"宿主 → 画布"单向 pilot（约半天）→ 再决定是否把写回也搬过去。
