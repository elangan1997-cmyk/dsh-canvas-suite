# v1.7.0 回归清单（REGRESSION-v1.7.0）

> 基线提交：`72bdc33`（见 BASELINE.md §0）
> 用途：每个 Phase 完成后逐项填写「重构后」列。**任何 FAIL 不得发布 v1.8.0**（执行文档 §32）。

## 状态定义

| 状态 | 含义 |
|---|---|
| PASS | 在本机实际执行并与基线行为一致 |
| FAIL | 执行后行为与基线不一致 |
| BLOCKED | 因前置条件（环境、依赖、账号）无法执行 |
| NOT SUPPORTED | 该平台/配置下本就不支持 |
| PENDING | 尚未执行 |

**填写纪律：** 静态检查通过、语法通过、副本一致，都**不能**写成功能 PASS；只有在 DSH 中实际操作过才能写 PASS。每次填写标注日期与提交号。

「基线状态」列说明：`PASS*` 表示 1.7.0 开发期间用户已在 DSH 实机逐项确认，但尚未作为正式回归基线重跑；正式基线由用户当前进行的「彻底卸载 → GitHub 全新安装」测试补齐后改为 `PASS`。
